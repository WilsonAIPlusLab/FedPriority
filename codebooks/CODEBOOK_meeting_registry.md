## Overview

This file is the master list of all FOMC meetings in the dataset. It records the basic administrative and contextual attributes of each meeting: date, type, presiding chair, available source documents, the policy decision taken, and any notable contextual information. It serves as the authoritative joining key for all other dataset files — `staff_scores_v6.csv` and `discussion_scores_v4_1.csv` carry a MEETING_DATE column that matches the registry meeting_date for all but 10 meetings (see Note 1; the shipped `data/derived/meeting_key_map.csv` maps the date keys of both score tables and of `meeting_variables.csv` to a registry meeting). The registry (320 rows, 1993-01-06 to 2026-09-16) covers meetings from 1993 onward, including regularly scheduled meetings, intermeeting conference calls, and unscheduled emergency actions. It distinguishes between meetings that produced scoreable documents (full transcripts or minutes) and those for which only limited records exist (e.g., conference call transcripts without a corresponding economic briefing).

## Unit of Observation

One row = one FOMC meeting or formal action, identified by meeting_date. Conference calls and intermeeting actions appear as separate rows from the surrounding scheduled meetings.

## Variable Definitions

| Variable | Type | Valid Values | Description |
|----------|------|--------------|-------------|
| meeting_date | Date (ISO 8601) | YYYY-MM-DD | The document-name date of the meeting, i.e. the date used in the source filenames. It is **not** uniformly the first day: it is the **last** day for 162 of the 172 two-day scheduled meetings and for all 1993-1995 meetings (e.g. 1993-02-03 for the 02-02/02-03 meeting), and the **first** day for 10 scheduled meetings (1996-01-30, 1996-07-02, 1997-02-04, 1997-07-01, 1998-02-03, 1998-06-30, 1999-02-02, 1999-06-29, 2003-09-15, 2012-10-23) and for four non-scheduled two-day rows (conference calls 2008-01-21, 2008-03-10, 2008-10-07; emergency 2020-03-02). Single-day meetings have one date. Use `start_date` and `end_date` for the actual span. Primary key for the registry. |
| start_date | Date (ISO 8601) | YYYY-MM-DD or empty | First day of the meeting, read from the minutes headers (the extraction script and its intermediate file are not shipped in this folder). Populated in 273 of 320 rows; empty in 47 (42 conference calls, 4 emergency actions, and the scheduled meeting 2007-08-07). Empty means the span is unknown, not single-day. |
| end_date | Date (ISO 8601) | YYYY-MM-DD or empty | Last day of the meeting, from the same source; populated in the same 273 rows, empty in the same 47. end_date minus start_date is 1 day in 176 rows and 0 in 97 (single-day: 96 scheduled meetings and the 2020-03-15 emergency), so duration can be computed where both are populated. |
| meeting_type | Categorical | `scheduled`, `emergency`, `conference_call` | The formal classification of the meeting. `scheduled` = one of the eight (historically fewer) regularly scheduled FOMC meetings in the annual calendar (269 rows). `emergency` = an unscheduled intermeeting action (6 rows: 2007-08-10, 2019-10-11, 2020-03-02, 2020-03-15, 2020-03-23, 2025-08-22); several are statement-only, and 2007-08-10 and 2020-03-02 rest on conference-call transcripts. The value `unscheduled` does not occur in the file. `conference_call` = an intermeeting conference call (45 rows), which may have produced only a brief record or a full transcript depending on the era and purpose. Conference calls rarely include a full economic briefing and are commonly N/A across most scoring dimensions. |
| chair | Categorical | `Greenspan`, `Bernanke`, `Yellen`, `Powell`, `Warsh` | The Federal Reserve Chair presiding at the time of the meeting. In this dataset (1993–2026), by first/last meeting in the file: Alan Greenspan (1993-01-06 to 2006-01-31; 132 rows), Ben Bernanke (2006-03-28 to 2014-01-29; 81), Janet Yellen (2014-03-04 to 2018-01-31; 33), Jerome Powell (2018-03-21 to 2026-04-29; 71), Kevin Warsh (2026-06-17 to 2026-09-16; 3). The chair was assigned by calendar date when the registry was built (the build script is not shipped; the data are consistent with a Powell/Warsh switch between 2026-04-29 and 2026-06-17, and the exact switch date used cannot be checked from this folder). Note that meetings at chair transitions may bear the outgoing or incoming chair depending on the exact date. |
| documents_found | String | Free text (comma-separated document types) | The source documents actually located and ingested for this meeting. Tokens: `minutes`, `transcript`, `confcall_transcript`, `statement`, `press_conference`. Values present (rows): `minutes,transcript,statement` 138; `minutes,transcript,statement,press_conference` 48; `minutes,statement,press_conference` 46 (recent meetings, no transcript yet); `minutes,transcript` 38; `confcall_transcript` 36; `confcall_transcript,statement` 10; `statement` 3; `confcall_transcript,statement,press_conference` 1. `minutes` alone, `transcript` alone and empty do not occur. This field is a free-text string enumerating document types, not a count. |
| documents_expected | String | Free text (comma-separated document types) | The source documents that would be expected for a meeting of this type based on standard FOMC practice. Values present (rows): `minutes,transcript,statement` 158; `minutes,transcript` 50; `confcall_transcript` 47; `minutes,statement,press_conference` 46; `minutes,transcript,statement,press_conference` 16; `statement` 3. The expectation is era-based and incomplete: 55 rows differ from documents_found, and all 55 of these differ only because `statement`/`press_conference` were found but not listed as expected. No true coverage gap remains: the 2007-06-28 statement was ingested on 2026-10-17. documents_expected for 2011-2018 is not filled in era-specific detail [Unverified: only the aggregate pattern was checked]. |
| rate_decision | String | Free text or empty | A human-readable description of the federal funds rate action taken at or immediately following the meeting. **Effectively unpopulated**: only 2 of 320 rows are non-empty, `cut_50bp` (2020-03-02) and `cut_100bp` (2020-03-15). The other 318 rows are empty, including every hike, cut and hold outside March 2020; "no change" never appears. Empty does not mean "no action". |
| target_rate | Numeric | Percentage (%) or empty | **Effectively unpopulated**: only 2 of 320 rows are non-empty, 1.125 (2020-03-02) and 0.125 (2020-03-15). Empty for all other rows, which does not mean a zero rate or no decision. Use an external source (e.g. FOMC statements) for rates. |
| special_notes | String | Free text or empty | Any anomalies, unusual context, or notable features of the meeting that are not captured by the other fields. 15 rows are non-empty; observed content is a note that a conference-call transcript also exists for the date, "statement only, no minutes" for emergency actions, the 2007-08-10 liquidity statement, and the 2020 COVID emergency cuts. Intended examples: notation that a meeting was called in response to a specific crisis event (9/11 attacks, Lehman failure, COVID-19 onset), notation that the economic briefing was abbreviated or omitted, notation of a policy framework review, or notation of a simultaneous intermeeting action. Empty for routine meetings with no notable features. |

## Notes

1. **Primary key and key map**: meeting_date is unique within this file (verified, 320 rows, sorted ascending). When joining to `staff_scores_v6.csv` or `discussion_scores_v4_1.csv`, join on meeting_date with SOURCE_TYPE as a second key dimension. Caveat: for 10 two-day meetings the score files use the **end** date, which is not a registry meeting_date (in the registry these meetings carry the first day): 1996-01-31, 1996-07-03, 1997-02-05, 1997-07-02, 1998-02-04, 1998-07-01, 1999-02-03, 1999-06-30, 2003-09-16, 2012-10-24. A plain join drops them. Use the shipped key map (next note).

1a. **`data/derived/meeting_key_map.csv`** (1,477 rows, 8 columns; one row per table, key and source_type; no duplicates). It maps the date keys of three tables to registry meetings.
   - `table`: `discussion_v4_1` (542 rows), `staff_patched_v6` (495; this is the keying of `staff_scores_v6.csv`) or `meeting_variables` (440).
   - `key`: the date key as it appears in that table (YYYY-MM-DD).
   - `source_type`: `minutes` or `transcript` for the two score tables; empty for all 440 `meeting_variables` rows (that table has one row per date).
   - `n_rows`: rows in that table for the key and source_type (always 1 in the shipped file).
   - `registry_meeting_date`: the matched registry `meeting_date`; empty when unmatched. Every non-empty value exists in the registry.
   - `match`: `exact` (1,327 rows; key equals a registry meeting_date), `inside_meeting_span` (33; key falls inside the start-to-end span of a registry meeting but is not its meeting_date: 11 in each of the three tables, the 10 end-date keys listed above plus, for `meeting_variables` only, 2008-03-11 -> 2008-03-10), `day_after_call` (2; `meeting_variables` keys 2008-01-10 -> 2008-01-09 and 2009-06-04 -> 2009-06-03), `unmatched` (115; all in `meeting_variables`, keys 2007-06-01 to 2009-06-26). No `alias_file_correction` value occurs in the shipped file.
   - `registry_type`: `meeting_type` of the matched meeting; empty for unmatched rows.
   - `note`: empty except for the 115 unmatched rows, which read `nearest registry date YYYY-MM-DD (N days)`.
   Both score tables have no unmatched key. After mapping, registry meetings with no row: `staff_scores_v6` 50 (45 conference calls and the 5 emergency actions other than 2020-03-15), `discussion_scores_v4_1` 3 (the statement-only emergency actions 2019-10-11, 2020-03-23, 2025-08-22), `meeting_variables` 8 (those same 3 plus the five 2026 meetings 2026-03-18, 04-29, 06-17, 07-29, 09-16). The 115 unmatched `meeting_variables` keys fall in 2007-06 to 2009-06 and match no meeting; that they are speech dates is stated in earlier project documentation and was not checked here. The earlier `tools/check_keys.py` and `02_registry/meeting_key_map.csv` of the project repository are not shipped; the figures above were recomputed from the shipped files.

2. **documents_found vs. documents_expected**: The difference between these two fields is the primary indicator of coverage gaps. Researchers analyzing the full 1993–present span should note that transcripts have a five-year declassification lag, so the 46 most recent rows have no transcript in either field (`minutes,statement,press_conference`), so no gap is flagged for them. No row has empty documents_found; the 3 `statement`-only rows have no scoreable document.

3. **Conference calls**: Most conference calls did not include a Tealbook economic briefing or a structured participant go-around. As a result, conference call rows in meeting_registry.csv have no rows in `staff_scores_v6.csv` (verified: none of the 45 conference_call rows is matched by the key map). `discussion_scores_v4_1.csv` does have transcript rows for all 45; that these show N/A for most dimensions was not rechecked here. meeting_type = `conference_call` misses two `emergency` rows that also rest on conference-call transcripts (2007-08-10, 2020-03-02). The more reliable flag is `documents_found` containing `confcall_transcript` (47 rows = 45 conference_call + 2 emergency).

4. **Chair field precision**: The chair variable reflects the presiding chair at the time of the meeting. It does not capture acting chairs (the file contains no acting-chair data), vice chairs presiding in the chair's absence, or cases where a new chair's first meeting was the final day of a two-day meeting that began under the previous chair. For precision analyses near transition dates, consult the special_notes field.

5. **target_rate empty cells**: The target_rate field is empty in 318 of 320 rows (see Variable Definitions); this is a coverage limitation, not a statement about the rate. An empty target_rate should not be interpreted as a rate of zero.

6. **rate_decision text format**: The rate_decision field is a free-text string and is not standardized to a fixed vocabulary. With only two populated values, neither this field nor target_rate differences can supply a rate-decision variable; build it from an external source.

7. **Meeting span (start_date, end_date)**: both columns come from the minutes headers and are populated together in 273 of 320 rows (268 of 269 scheduled meetings, three 2008 conference calls and two 2020 emergency rows); the other 47 are blank, so blank means unknown, not single-day. Because `meeting_date` is the last day for most meetings but the first day for 14 rows (see the meeting_date definition), compute duration as end_date minus start_date, not from meeting_date. rate_decision and target_rate remain unfilled (no source).
